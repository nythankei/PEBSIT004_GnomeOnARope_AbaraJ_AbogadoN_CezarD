# Gnomewell

## Description

Gnomewell is a 2D mobile action game where players guide a gnome lowered into a dangerous well. The goal is to collect treasure while carefully avoiding traps, using rope controls with varying speeds.

## Engine / Language / Version

* Unity 2021.3.5f1  
* C#

## Controls (Android Touch)

* **Up Fast** – Quickly raise the rope  
* **Up Slow** – Slowly raise the rope  
* **Down Fast** – Quickly lower the rope  
* **Down Slow** – Slowly lower the rope

## How to Run

### 1. Download the Game Build
Get the ZIP file from here:  
[https://github.com/nythankei/PEBSIT004_GnomeOnARope_AbaraJ_AbogadoN_CezarD/releases/download/GnomeWell/release.zip](https://github.com/nythankei/PEBSIT004_GnomeOnARope_AbaraJ_AbogadoN_CezarD/releases/download/GnomeWell/release.zip)

### 2. Extract the ZIP File
1. Right-click the ZIP file → select **Extract All…**  
2. Choose a destination folder (e.g., `C:\Games\Gnomewell`)  
3. Click **Extract**  

### 3. Open the Project in Unity Hub
1. Launch **Unity Hub**.  
2. Click **Open** → navigate to the extracted project folder (the one containing the `Assets` and `ProjectSettings` folders).  
3. Select the folder and click **Open Project**.  
4. When prompted, choose the Unity Editor version you have installed (e.g., `6000.2.4f1`) and set the current platform to **Android**, then click **Open with [Editor Version]**.  
5. If prompted for upgrade or downgrade, just click **Yes** to all.  

> 💡 **Note:** Make sure your Unity Editor supports Android build support for it to work properly.

### 4. Wait for the Project to Load
Unity may take a few minutes to import assets and compile scripts the first time.

### 5. Open the Menu Scene
1. In the **Project** window (bottom of the Unity Editor), go to:  
   `Assets → Scenes`  
2. Double-click **Menu**.  
3. Wait until loading is finished.

### 6. Run the Game
Click the **Play** button at the top center of the Unity Editor to start the game.

## Known Issues / Limitations

* Rope physics may jitter when switching between fast/slow inputs.  
* No gamepad or keyboard support (Android touch only).
